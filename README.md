# 研墨 · 考研英语

离线可用的考研英语精读手册：词汇、长难句、阅读、完形/新题型、翻译、写作与备考规划。

- 纯 HTML/CSS/JS，无构建步骤、无外部依赖、无网络请求
- 学习数据存于浏览器本机（localStorage），支持导出 / 导入
- 阅读训练采用“依据先行”：先标依据段，再选答案
- 内容为原创仿真材料，不是历年真题原文

在线访问：https://lsj666nsyw.github.io/yanmo-kaoyan/

## 内容

- 词汇 1,473 条，全部带用法、义项、搭配、例句、近义/词族与辨析
- 长难句 40 句，逐句拆主干、标成分
- 阅读 22 篇 / 110 题，含证据链与 40 道干扰项归因
- 完形 5 套、七选五 5 套、排序题 3 套、小标题匹配 3 套
- 翻译 52 句 + 英语二段落翻译
- 写作：小作文 12 篇、大作文 12 篇，句型/常用句 17 组、替换 40 组
- 发音：系统英文语音优先；无英文语音时自动使用内置 meSpeak 离线语音，可在“我的记录”里切换
- 单文件版：`研墨-考研英语.html`（约 4 MB，含词库与离线语音，可直接双击打开）

## 数据与许可

- 词条例句、搭配、近义与词族：KyleBing/english-vocabulary（BSD-3-Clause）
- 基准考研词表：NETEMVocabulary（CC BY-NC-SA 4.0）
- 离线语音：meSpeak / eSpeak（GNU GPL），许可见 `vendor/mespeak/LICENSE.txt`
- 阅读、翻译、写作材料为自编仿真内容，不是历年真题原文
- 本项目仅用于个人学习，非商业分发

## 生成脚本

- `tools/build-vocab-extra.js`：从公开词库补充 300 个词条
- `tools/build-vocab-detail.js`：生成 1,473 条完整词条卡
- `node build-single.js`：重建单文件版
